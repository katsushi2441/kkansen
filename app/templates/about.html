データについて

全国（都道府県）

国立健康危機管理研究機構（JIHS）の「IDWR速報データ」を毎週取り込みます。定点把握の19疾患と急性呼吸器感染症（ARI）の都道府県別の報告数・定点当たり報告数、全数把握の感染症の届け出数、今年1週からの推移です。速報は週の終わりからおよそ1〜2週間後に出て、あとで確定値に直ることがあります。{% if idwr %}いまの最新は{{ idwr.year }}年{{ idwr.week }}週です。{% endif %}

名古屋市（区）

名古屋市感染症情報センターの「名古屋市感染症発生動向調査 週報」から、16区の患者報告数と区ごとの定点数を読み取り、定点当たり報告数を計算しています。新型コロナは市が区ごとの定点当たりを出していないため、報告数で示します。{% if ngy %}いまの最新は{{ ngy.week }}週です。{% endif %}

学級閉鎖

名古屋市の「集団かぜ（インフルエンザ様疾患）による学級閉鎖等の状況」（前日判明分まで）を毎日取り込みます。

警報・注意報レベルの目安

国の感染症発生動向調査で使われている基準値（定点当たり）を、都道府県・区の値に当てはめています。インフルエンザは警報30（10未満で終息）・注意報10、溶連菌は警報8、感染性胃腸炎は警報20、手足口病は警報5、水痘は警報2・注意報1、りんご病は警報2、プール熱は警報3、ヘルパンギーナは警報6、おたふくかぜは警報6・注意報3、はやり目は警報8、急性出血性結膜炎は警報1です。正式な警報・注意報は自治体が保健所の管内ごとに判断して発表するので、ここでの表示は目安です。

地図

都道府県と名古屋市の区の境界は「国土数値情報（行政区域データ）」（国土交通省・CC BY 4.0）を加工して作成しました（形を簡単にし、小さな島を省いています）。背景の地図は OpenFreeMap（© OpenMapTiles・Data from OpenStreetMap）です。

AIから使う（MCP）

Claude や ChatGPT などの AI エージェントから、このサイトの数字を直接引けます（MCP＝Model Context Protocol。読み取り専用・登録不要）。接続先は {{ public }}/mcp です。

Claude Code なら claude mcp add --transport http kkansen {{ public }}/mcp。Claude のアプリでは「コネクタを追加」に同じ URL を入れます。

使える道具：いま流行っている感染症（全国）・都道府県の流行状況・感染症ごとの都道府県一覧・名古屋市の区ごとの流行状況・名古屋市の学級閉鎖・今年の週ごとの推移・全数把握の感染症・住所から地域の流行状況。どの答えにも、対象の週と出典の URL が付きます。住所は都道府県（名古屋市は区）を決めるためだけに使い、保存しません。

このサイトがしないこと

体調の判断、受診すべきかどうか、学校・施設の対応の助言はしません。数字は公式の値をそのまま載せ、出典へのリンクを付けています。
